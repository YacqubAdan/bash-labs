## 🔫 Bash Playground Script List

1. **[cleanup-old-files](https://github.com/YacqubAdan/bash-labs/blob/projects/automation-tasks/playground/cleanup-old-files.sh)** 
-  This script deletes files in a given directory that are older than 30 days
2. **[git-installer](https://github.com/YacqubAdan/bash-labs/blob/projects/automation-tasks/playground/git-installer.sh)**
- This script will install git depending on the operating system the user is running on
3. **[init-js-project](https://github.com/YacqubAdan/bash-labs/blob/projects/automation-tasks/playground/init-js-project)**
- This script initialises a boilerplate for a standard vanilla js project 
4. **[organise-files.sh](https://github.com/YacqubAdan/bash-labs/blob/projects/automation-tasks/playground/organise-files.sh)**
- This script organises a messy directory into a much cleaner structured folder
5. **[list-dir-details](https://github.com/YacqubAdan/bash-labs/blob/projects/automation-tasks/playground/list-dir-details.sh)**
- This script outputs a common description of a given directory and it's children
